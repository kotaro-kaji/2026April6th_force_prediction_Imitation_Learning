# Prior-Art Difference: World Model vs Force Imagination

User original note on 2026-05-21.

河原塚さんの研究然り、

World Model と 模倣学習ポリシーのエンコーダ部分を共通して一緒に持たせて、世界予測ヘッドとaction出力ヘッドだけを分けるという動きはすでにあり、
World Model的にカメラ画像やそれに相当するものを予測 → 予測誤差によってエンコーダ部分を補正することで、World Modelと模倣学習ポリシーを同時にオンライン更新

ということまですでにかなりやられています。

ただし、そこでの主題は、本研究のようなオブジェクトの内部物性の話ではなく、

以下のような、視覚的なOODや、オブジェクトの交換にどこまで対応できるか、河原塚さんの論文のようにカメラ位置をわずかにずらすということへの対応性に関する実験のみしか行われていません。
Pushingタスクに限定すれば、オブジェクトを押すと、重心周りに回転するはずなので、押した後のカメラ画像を予測することは、重心を予測する（エラーの原因は重心の位置を間違えたため）ことを意味します。また、コンプライアンス制御で押してもあまりオブジェクトが動かなかった場合、既存手法では、摩擦係数や物体の重量に相当する部分を非明示的にPBやエンコーダーの重みとして更新します。つまり、画像を予測するタイプの既存手法ですでに、私が今取り組んでいる、PushTタスクは実現できるのではないか、と考え始めました。

ただし、どの研究でも内部物性の違いを主題にした実験は１つもないため、できるかどうかの確認は一切されていません。ただ、既存手法でやってみればできてしまう可能性はあります。
PushTタスクのみで検証し、「内部物性の違いに対応し、高い成功率を誇る手法を提案します」と主張しても、たしかにそれを力覚センサの予測で解いた例はないが、既存の手法でも理屈上解けていた問題なのではないか、という指摘が予想され、否定できません。

Wipingで具体的に行うつもりだったタスクは、異なる柔らかさのスポンジでのホワイトボードの汚れの除去です。このタスクであれば、スポンジの潰れ具合を常にカメラで捉え続けることは現実的ではなく、力覚センサの予測でなければ、解けない問題であったという主張に説得力が出ると思いました。

最も望ましい実験結果は、自分の提案手法であれば、内部物性の異なるPushTでも高い成功率を誇れる上に、異なる内部物性のスポンジを用いたWipingタスクでも高い成功率となることであり、その主張がベストだと考え、まずはシミュレーションで検証できるPushTから実装を始めていたという流れになります。
